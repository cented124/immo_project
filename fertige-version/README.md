# Raumwerk – fertige Version

**Version 1.0.0 für Windows 10/11 x64, ohne Docker.**

1. [Fertiges Windows-Paket herunterladen](https://github.com/cented124/immo_project/releases/download/v1.0.0/Raumwerk-Windows-ohne-Docker.zip).
2. ZIP vollständig in einen lokalen Ordner entpacken.
3. `STARTEN.cmd` öffnen und den Administrator im Browser anlegen.

Bei einem Update vorher `SICHERN.cmd` verwenden. In einen neuen Ordner entpacken und den **vollständigen Ordner DATEN** aus der alten Installation übernehmen. Danach `STARTEN.cmd` öffnen.

[Kurze Windows-Anleitung](../ANLEITUNG-WINDOWS.md) · [Testergebnisse](../docs/RELEASE-1.0.0.md) · [Release mit allen Dateien](https://github.com/cented124/immo_project/releases/tag/v1.0.0)

## Eigener Versionsordner

[Version 1.0.0](1.0.0/) enthält das vollständige Quellpaket samt Prüfsumme. Dieses kleinere Paket lädt beim ersten Start die geprüften Laufzeiten nach und benötigt dabei Internet. Für den einfachen Start das **fertige Windows-Paket oben** nehmen.
